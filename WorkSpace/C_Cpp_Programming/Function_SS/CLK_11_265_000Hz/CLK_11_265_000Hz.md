Le fonction pricipales de fichier CLK_11_265_000Hz.sh est d'e prendre une valeur de frequence en argument est utiliser Pigpio pour envoyer la cette frequence sur la surtie GPIO4 = GPCLK0.
On ne peux pas utiliser Pigpio et WiringPi en meme temps donc in faut assurer que les deux ne sont pas activées en meme temps. Cette fichier verifie si le Pigpio etait deja en cours d'execution sinon le script lance le Pigpio, en suite la frequence est reglé a la frequence donnée dans l'argument de fichier de script bash. et une fois que c'est fait le script "desactive"(kill the task) pigpio.

voici les lignes de script importantes :


```
sudo pigpiod
pigs hc $GPIO_PIN $FREQ # pigs hc 4 11265000, il faut remplacer les variables par des valeurs
sudo killall pigpiod
```
